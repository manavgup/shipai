How It Works

Each cycle brings the agent closer to the answer

1
Thought
The agent reasons about the current state and plans
"I need to calculate 15 × 8 first."
2
Action
The agent executes a tool call
multiply(15, 8)
3
Observation
The agent receives and processes the result
→ 120
✓
Loop or Answer
More steps? → Loop back to Thought. Solved? → Return the final answer.

Working Example

▸

"If 15 items cost $8 each and 20 items cost $8 each, what's the total revenue?"

Thought 1
First I need revenue from 15 items at $8 each
Action 1
multiply(15, 8)
Observe 1
120
Thought 2
Now I need revenue from 20 items at $8 each
Action 2
multiply(20, 8)
Observe 2
160
Thought 3
Now I add both revenues together
Action 3
add(120, 160)
Observe 3
280
Answer
The total revenue is $280 ✓
